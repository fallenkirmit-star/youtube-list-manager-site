YouTube List Manager

A personal playlist assistant for one YouTube account.

YouTube List Manager watches a hand-picked list of YouTube channels and, when a new video appears, adds it to the account owner's own playlists so nothing good gets missed in the feed.

It is a private, single-user tool. It runs only on the owner's own account, with the owner's own sign-in, and it only ever adds videos to the owner's own playlists. It is not a public service and has no other users.
